# Reflex Rush (IEEE VIT Pune)
Deploy:
1. Push this folder to GitHub, import it in Vercel (Framework: Other, Output Directory: public).
2. Vercel > Storage > add an Upstash Redis (Marketplace) and connect it to the project.
3. Settings > Environment Variables: add ADMIN_PASSWORD (any strong password).
4. Redeploy. Game: /  Admin: /admin.html
Edit branch names in api/_config.js.
